# Карта комплекта документов

| Раздел | Содержимое |
|---|---|
| `product/` | Продуктовая задача, типовые сценарии, границы 0.1 |
| `architecture/` | Схема компонентов, модель данных, состояния, семейства, политики, кеш и восстановление |
| `specifications/` | Точные контракты GitHub, APT, DNF, CLI/API и ошибок |
| `decisions/` | Утверждённые ADR: принятое решение, причины, альтернативы, ограничения |
| `research/` | Блокирующие R-001…R-004, методики и шаблон доказательств |
| `testing/` | Матрица Linux, E2E, негативные тесты, условия альфы |
| `process/` | Операционные инструкции агенту, изолированные VM/credentials и утверждённый ADR-015 baseline Rust с обязательными прототипными проверками |
| `references.md` | Первичная документация APT, DNF, systemd, GitHub |
| `roadmap.md` | Последовательность возможностей и контрольные рубежи |

**Версии документов:** комплект соответствует состоянию обсуждения от 18 октября 2026. Любые непроверенные механизмы отмечены `RESEARCH_REQUIRED` или `ASSUMPTION` и привязаны к R-исследованию. Нельзя объявлять их подтверждёнными без протокола результатов.
