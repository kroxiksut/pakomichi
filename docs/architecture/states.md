# Модель состояний и переходов

## Источник

`discovered` → `registered` → `observing` → `active` → `suspended` / `disabled`; из `suspended` в `active` только после устранения причины и повторной проверки. `disabled` не удаляет `ForgeRepository` до выполнения явной операции удаления.

| Событие | До | После | Правило |
|---|---|---|---|
| `source add` | отсутствует | discovered/registered | Закрепить ID репозитория и владельца |
| обнаружение конфликтующего системного пакета | registered | observing | Не менять поставщика |
| явное согласие + успешная симуляция | observing | active | Применить только наши файлы политики |
| чужой repo ID по старому URL | любое активное | suspended | Никакого автоматического relink |
| смена владельца при том же ID | active | suspended | Требуется явное подтверждение |
| недействительная аттестация | active | suspended или исключение конкретного выпуска | По масштабу нарушения, не стирать подтверждённую историю |
| выбранный пакет больше не доступен | active | observing/suspended package | Не переключаться на форк |
| временно нет сети | active | active + stale status | Использовать последний доверенный снимок лишь по freshness policy |
| пользователь удалил источник | любое | disabled/deleted | Приложения остаются установленными |

## Версия / артефакт

`discovered → candidate → verified → eligible → published → retired`. Ответвления `held` (конфликт/совместимость), `rejected` (доверие/подмена), `revoked` (явная блокировка). `verified` ≠ `eligible`: исходный файл подлинный, но может быть несовместим.

## Снимки

`building → signed → verified → staged → published → retired → collected`. `failed` из любого состояния до published; опубликованный снимок **не модифицируется**. Старые снимки держим, пока существуют запросы или не истёк период безопасной ссылочной доступности.

## Установленное состояние

Pakomichi **наблюдает** за APT/dpkg или DNF/rpm; он не единственный реестр установленных пакетов. Расхождения выставляют `external_change_detected`, не приводят к самостоятельной переустановке.

## Ошибки

Обязательны machine-readable codes, указанные в `docs/specifications/errors.md`, и понятная человеку причина: что произошло, какой файл/пакет затронут, можно ли продолжить, требуется ли выбор администратора.
