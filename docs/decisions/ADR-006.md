# ADR-006 — RPM-подписи и аттестации как разные границы

**Статус:** принято как проектное решение (концепция); эксплуатационные свойства проверяются исследованиями.
**Дата:** 2026-10-18.

## Контекст

repo_gpgcheck != pkg_gpgcheck. Разница DNF4/DNF5 и принудительная системная политика требуют адаптера.

## Решение

Локальный repo signer подписывает метаданные. RPM с подписью издателя проверяется штатно. Неподписанный attestated RPM — только при явной разрешённой политике конкретного репозитория, если обязательная системная проверка пакета не запрещает. Не переподписывать RPM.

## Альтернативы и причины отказа

Переподпись чужих RPM / глобальное gpgcheck=0 / считать GitHub attestation встроенной GPG-подписью — отклонены.

## Последствия и ограничения

Решение обязательно для проектирования API, состояния и тестов. Если конкретная версия ОС не обеспечивает указанное поведение, нельзя объявлять поддержку этой комбинации без ограничения функциональности. Любое изменение решения требует новой superseding ADR и подтверждения владельца проекта.

## Подтверждение

R-002 делает матрицу allow/block на DNF4, DNF5 и enforced RPM policy.
