# ADR-011 — Один локальный ключ репозиторных метаданных для установки

**Статус:** принято как проектное решение (концепция); эксплуатационные свойства проверяются исследованиями.
**Дата:** 2026-10-18.

## Контекст

Сокращает эксплуатационную сложность; центральный ключ становится доверенным центром локальной системы и требует бэкапа/ротации.

## Решение

Для 0.1 использовать отдельный локальный ключ для подписания всех наших логических repo, с жёсткими правами; каждый repo имеет отдельную политику происхождения. Ключ не подписывает DEB/RPM как издатель.

## Альтернативы и причины отказа

Один ключ на каждый Git-репозиторий без операционной потребности / привилегии у downloader — отложено/отклонено.

## Последствия и ограничения

Решение обязательно для проектирования API, состояния и тестов. Если конкретная версия ОС не обеспечивает указанное поведение, нельзя объявлять поддержку этой комбинации без ограничения функциональности. Любое изменение решения требует новой superseding ADR и подтверждения владельца проекта.

## Подтверждение

R-002/R-004 проверяют доверие локальных метаданных, потерю/ротацию ключа.
