# ADR-001 — Закрепление конкретного Git-репозитория

**Статус:** принято как проектное решение (концепция); эксплуатационные свойства проверяются исследованиями.
**Дата:** 2026-10-18.

## Контекст

URL может быть переназначен новому репозиторию; форки и репозитории автора не являются наследниками доверия.

## Решение

Идентичность источника — `(forge, stable repository_id)` плюс `owner_id` и история canonical URL. Обновления только из него; rename при тех же ID допустим после проверки; owner transfer требует подтверждения.

## Альтернативы и причины отказа

По URL и имени проекта / искать самый свежий fork — отклонено; ключ один лишь Git commit — недостаточен для закрепления издателя.

## Последствия и ограничения

Решение обязательно для проектирования API, состояния и тестов. Если конкретная версия ОС не обеспечивает указанное поведение, нельзя объявлять поддержку этой комбинации без ограничения функциональности. Любое изменение решения требует новой superseding ADR и подтверждения владельца проекта.

## Подтверждение

R-003 проверяет сравнение sourceRepositoryIdentifier, owner transfers и same-name recreation.
