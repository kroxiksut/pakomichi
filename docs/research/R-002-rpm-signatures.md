# R-002 — RPM: оригинальная подпись, подписанный repodata, Attested

Результат этого протокола обязателен до реализации RPM repodata, подписей и политики DNF.

## Гипотеза

DNF4 и DNF5 разделяют проверку репозитория и пакета; системная политика может требовать встроенную подпись RPM. Отдельная проверка GitHub attestation **не превращает** RPM в подписанный RPM.

## Fixtures и матрица

2 одинаковых по содержимому тестовых RPM (с подписью тестового ключа и неподписанный), 1 RPM с испорченной подписью, 1 пакет с доказанным подписанным provenance для тестового проверяющего, 1 RPM без подтверждения. Репозитории: подписанные тестовым ключом метаданные и намеренно некорректная подпись.

| DNF | RPM signature | Repo signature | Mandatory policy | Ожидаемое |
|---|---|---|---|---|
| 4 | valid | valid | требует | allow |
| 4 | none | valid | требует | block |
| 4 | none + verified attestation | valid | допускает явный режим | allow только после явного согласия |
| 5 | valid | valid | требует | allow |
| 5 | none | valid | требует | block |
| 5 | corrupted | valid | любое | block |
| 4/5 | valid | invalid | repo check on | block |

Зафиксировать реальные настройки `gpgcheck`, `repo_gpgcheck`, `pkg_gpgcheck`, `gpgcheck_policy`, `%_pkgverify_level` и отличия синтаксиса. Не подставлять команды, не поддерживаемые конкретной версией DNF.

## Эксперименты

- Получить фактическое effective значение проверки при разных конфигурациях.
- Проверить, что локальный signer только подписывает `repomd.xml`, не модифицирует RPM.
- Подменить RPM после формирования метаданных и убедиться, что пакет не устанавливается.
- Запретить отключение глобальной политики и проверить корректное сообщение об отказе.
- Проверить локальную ключевую ротацию для метаданных и восстановление после потери private key на тестовом хосте.

## Результат

PASS только при документированной матрице, в которой неподписанный RPM никогда не принимается вопреки обязательной политике ОС. **Fallback:** на системах с обязательной подписью только нативно подписанные RPM; Attested unsigned held.
