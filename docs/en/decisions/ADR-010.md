# ADR-010 — Failure must not affect applications or system sources

**English** · [Русский](../../ru/decisions/ADR-010.md)

**Status:** accepted as a design decision (concept); operational properties are verified by research tasks.  
**Date:** 2026-10-18.

## Context

A GitHub failure must not corrupt the cache or substitute bytes. Acknowledged: the source may be unavailable when the adapter fails.

## Decision

Network failure / staleness / corruption are distinct states. Preserve the published verified snapshot; do not re-sign stale as fresh; return correct errors from our source; removing Pakomichi does not remove installed packages.

## Alternatives and reasons for rejection

Hiding the error / issuing a new Release without network verification / automatically removing the attached package — rejected.

## Consequences and constraints

This decision is mandatory for the design of the API, state, and tests. If a specific OS version does not provide the specified behavior, support for that combination must not be declared without restricting functionality. Any change to this decision requires a new superseding ADR and confirmation by the project owner.

## Verification

R-004; powerloss/disk-full/offline/uninstall tests.
