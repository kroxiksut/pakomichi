# ADR-008 — Atomic generations of repository snapshots

**English** · [Русский](../../ru/decisions/ADR-008.md)

**Status:** accepted as a design decision (concept); operational properties are verified by research tasks.  
**Date:** 2026-10-18.

## Context

APT/DNF may fetch metadata in parallel. Atomicity of a single `current` write without immutable indexes is insufficient.

## Decision

Immutable generations. APT `Acquire-By-Hash`, content-addressed package paths, verification of signatures and references before publication. RPM repomd plus indexes are consistent. Old generations are retained while referenced.

## Alternatives and reasons for rejection

Overwriting Packages/RPM metadata in place / deleting files of active generations on a timer — rejected.

## Consequences and constraints

This decision is mandatory for the design of the API, state, and tests. If a specific OS version does not provide the specified behavior, support for that combination must not be declared without restricting functionality. Any change to this decision requires a new superseding ADR and confirmation by the project owner.

## Verification

R-004, especially under parallel apt update/upgrade and interrupted publication.
