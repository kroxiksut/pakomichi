# Негативные тесты (обязательны)

[English](../../en/testing/negative.md) · **Русский**

| ID | Входные данные / атака | Ожидаемое поведение |
|---|---|---|
| N-001 | Fork с большей версией того же приложения | Игнорировать, repo ID mismatch |
| N-002 | Другой repo того же owner выпускает одноимённый пакет | Не рассматривать |
| N-003 | Старый URL ведёт на вновь созданный repo | Suspend + `E_REPO_ID_CHANGED` |
| N-004 | Transfer прежнего repo другому owner | Suspend до подтверждения |
| N-005 | Mutable asset заменён другими байтами | `E_ASSET_MUTATED`, не перезаписать SHA |
| N-006 | Сертификат attestation другого repo/подписанта | Reject |
| N-007 | Только API digest без подписи | Недостаточно для автоматического verified |
| N-008 | `sampleapp-glibc` с Provides glibc | Hold / конфликт системного namespace |
| N-009 | Неудовлетворимая glibc из следующего релиза | Hold версии, ничего не скачать из Git |
| N-010 | Одинаковая версия двух DEB с разным sha | No automatic source switch |
| N-011 | RPM без подписи при mandatory policy | Block |
| N-012 | Некорректный InRelease/repomd signature | Ошибка штатного менеджера |
| N-013 | GitHub недоступен / 429 | Последний проверенный снимок в пределах freshness, diagnostics |
| N-014 | Ссылка на пакет, удалённый с GitHub, и нет blob | Корректная ошибка, без подмены |
| N-015 | Падение во время публикации индексов | Нет смешивания поколений |
| N-016 | Disk full во время скачивания | Не отдавать частичный пакет, active snapshot цел |
| N-017 | Пакет в кеше поменяли после verification | Digest mismatch, не отдавать |
| N-018 | `../` и symlink в blob path | Не выходит из собственного каталога |
| N-019 | Asset redirect на 127.0.0.1/169.254.169.254 | Запрет SSRF, без запросов к локальным службам |
| N-020 | Злонамеренный malformed DEB/RPM | Не исполнять установочные сценарии, limits, process not root |
| N-021 | Пользователь вручную удалил/обновил установленную программу | Reconcile state; без автоматической переустановки |
| N-022 | Удалить Pakomichi после установки программы | Программа остаётся, чужие repo files не меняются |
| N-023 | Потеря ключа local signer | Нет молчаливой переинициализации доверия; процедура восстановления |
| N-024 | Ошибка конфигурации DNF/APT во время apply | Rollback или явный recoverable state |
| N-025 | POST на loopback repository endpoint | Не выполняет конфигурационные действия |

Каждый тест должен сохранять фактический результат, ожидаемый reason code и версии тестовой среды. Нельзя считать одно `unit test passes` проверкой работы реального APT/DNF.
