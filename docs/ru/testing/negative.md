# Негативные тесты (обязательны)

[English](../../en/testing/negative.md) · **Русский**

| ID | Входные данные / атака | Ожидаемое поведение |
|---|---|---|
| N-001 | Fork с большей версией того же приложения | Игнорировать, repo ID mismatch |
| N-002 | Другой repo того же owner выпускает одноимённый пакет | Не рассматривать |
| N-003 | Старый URL ведёт на вновь созданный repo | Suspend + `E_REPO_ID_CHANGED` |
| N-004 | Transfer прежнего repo другому owner | Suspend до подтверждения |
| N-005 | Mutable asset заменён другими байтами | `E_ASSET_MUTATED`, не перезаписать SHA |
| N-006 | Сертификат attestation другого repo/подписанта | Reject |
| N-007 | Только API digest без подписи | Недостаточно для автоматического verified |
| N-008 | `sampleapp-glibc` с Provides glibc | Hold / конфликт системного namespace |
| N-009 | Неудовлетворимая glibc из следующего релиза | Hold версии, ничего не скачать из Git |
| N-010 | Одинаковая версия двух DEB с разным sha | No automatic source switch |
| N-011 | RPM без подписи при mandatory policy | Block |
| N-012 | Некорректный InRelease/repomd signature | Ошибка штатного менеджера |
| N-013 | GitHub недоступен / 429 | Последний проверенный снимок в пределах freshness, diagnostics |
| N-014 | Ссылка на пакет, удалённый с GitHub, и нет blob | Корректная ошибка, без подмены |
| N-015 | Падение во время публикации индексов | Нет смешивания поколений |
| N-016 | Disk full во время скачивания | Не отдавать частичный пакет, active snapshot цел |
| N-017 | Пакет в кеше поменяли после verification | Digest mismatch, не отдавать |
| N-018 | `../` и symlink в blob path | Не выходит из собственного каталога |
| N-019 | Asset redirect на 127.0.0.1/169.254.169.254 | Запрет SSRF, без запросов к локальным службам |
| N-020 | Злонамеренный malformed DEB/RPM | Не исполнять установочные сценарии, limits, process not root |
| N-021 | Пользователь вручную удалил/обновил установленную программу | Reconcile state; без автоматической переустановки |
| N-022 | Удалить Pakomichi после установки программы | Программа остаётся, чужие repo files не меняются; не остаётся ни одного файла `.repo`/`.sources` Pakomichi, операции DNF/APT с репозиториями дистрибутива проходят (ADR-021) |
| N-023 | Потеря ключа local signer | Нет молчаливой переинициализации доверия; процедура восстановления |
| N-024 | Ошибка конфигурации DNF/APT во время apply | Rollback или явный recoverable state |
| N-025 | POST на loopback repository endpoint | Не выполняет конфигурационные действия |
| N-026 | Артефакт, чей `Obsoletes`/`Replaces` называет пакет системного пространства имён, с любым ограничением версии | Hold, `E_SYSTEM_PACKAGE_CONFLICT`, до публикации (ADR-022) |
| N-027 | Другой источник, в том числе обновление безопасности дистрибутива, предлагает большую версию активированного имени или члена семейства | Издатель не меняется при штатной команде обновления дистрибутива; уведомление называет другой источник и версию (ADR-022) |
| N-028 | DNF-репозиторий Pakomichi недоступен (соединение отклонено или 503) | Ошибка DNF называет репозиторий Pakomichi, установленный экземпляр сохраняется, Pakomichi не переключается на `skip_if_unavailable=True` и не трогает чужие файлы репозиториев (ADR-021) |
| N-029 | Сокет в `service-start-limit-hit` после цикла падений | `pchi doctor` сообщает о сбое и команду восстановления; восстановление выполняется только после явного подтверждения администратора, никогда через status API или HTTP (ADR-021) |
| N-030 | Запрос глобально отключить проверку подписей RPM, либо RPM по Attested-исключению с несовпадающим digest или attestation | Глобальное отключение отклоняется до запуска DNF; RPM удерживается с `E_SIGNATURE_POLICY` или отклоняется (ADR-023) |
| N-031 | Эффективная настройка DNF, перечитанная после записи, отличается от записанной | `E_ADMIN_APPLY_FAILED`, rollback (ADR-023) |
| N-032 | DNF-источник превышает максимальную свежесть | Публикуется подписанное пустое поколение; установленные пакеты остаются; операции DNF с репозиториями дистрибутива проходят; пакеты источника больше не предлагаются; успешный `sync` возвращает их; `E_SOURCE_STALE` (ADR-024) |
| N-033 | Повтор старого подписанного поколения или запрос перевести `current` назад | Никогда не отдаётся как `current`; ID поколений не переиспользуются (ADR-024) |
| N-034 | Непривилегированный локальный пользователь занимает loopback-порт, пока сокет не работает | Измерить с сокетом на привилегированном порту; выбор порта следует результату (ADR-024, пункт 6) |
| N-035 | Astra Linux с включённой замкнутой программной средой, настроенной, но не действующей, или нечитаемой | Активация отклоняется, каждый артефакт удерживается с кодом `E_EXECUTION_POLICY` (ADR-025) |
| N-036 | Применение, запущенное с уровня целостности 0 на Astra Linux | Сообщается как проблема уровня целостности (`E_SECURITY_CONTEXT`), а не ошибка пакета; ничего не применено частично (ADR-025) |
| N-037 | Pinned-источник с `--policy preferred`, либо имя Pinned-пакета, которое принадлежит системному пространству имён или установлено из источника дистрибутива | Отклоняется; пакет дистрибутива никогда не вытесняется, даже явной миграцией (ADR-027) |
| N-038 | Релиз с более слабыми доказательствами, чем уровень доверия источника | Hold с `E_EVIDENCE_DOWNGRADE`; уровень не понижается (ADR-027) |
| N-039 | Pinned-релиз без одобрения; asset изменён после одобрения | Не публикуется (`E_RELEASE_APPROVAL_REQUIRED`); изменённый asset — `E_ASSET_MUTATED` (ADR-027) |
| N-040 | Согласие на Pinned или одобрение релиза через status API, HTTP или `--yes` | Отклоняется (ADR-027) |

Каждый тест должен сохранять фактический результат, ожидаемый reason code и версии тестовой среды. Нельзя считать одно `unit test passes` проверкой работы реального APT/DNF.
