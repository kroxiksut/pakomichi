# ADR-010 — Отказ не должен затрагивать приложения и системные источники

[English](../../en/decisions/ADR-010.md) · **Русский**

**Статус:** принято как проектное решение (концепция); эксплуатационные свойства проверяются исследованиями. Частично заменено ADR-021.  
**Дата:** 2026-10-18.

## Контекст

Отказ GitHub не должен повреждать кеш или подменять байты. Признать: источник может быть недоступен при падении адаптера.

## Решение

Сетевой отказ / устаревание / повреждение — разные состояния. Сохранять опубликованный проверенный снимок; не переподписывать stale как fresh; корректные ошибки нашего источника; удаление Pakomichi не удаляет установленные пакеты.

## Альтернативы и причины отказа

Скрывать ошибку / выпускать новый Release без сетевой проверки / автоматически удалять установленный пакет или снимать его с опубликованного снимка — отклонено.

## Последствия и ограничения

Решение обязательно для проектирования API, состояния и тестов. Если конкретная версия ОС не обеспечивает указанное поведение, нельзя объявлять поддержку этой комбинации без ограничения функциональности. Любое изменение решения требует новой superseding ADR и подтверждения владельца проекта.

## Подтверждение

R-004; тесты powerloss/disk-full/offline/uninstall.
