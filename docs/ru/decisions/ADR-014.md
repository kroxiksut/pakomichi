# ADR-014 — Границы 0.1 alpha и явные отложенные возможности

[English](../../en/decisions/ADR-014.md) · **Русский**

**Статус:** принято как проектное решение (концепция); эксплуатационные свойства проверяются исследованиями.
**Дата:** 2026-10-18.

## Контекст

Проверяем основную ценность прежде расширения платформ; WinGet исследовать параллельно, но не блокировать.

## Решение

0.1: GitHub публичные Releases, DEB/APT и RPM/DNF4/DNF5, CLI, read-only API, доверие/кеш/отказы. WinGet, GitLab/Gitea/Forgejo, GUI, tar-to-package, community catalog — после alpha.

## Альтернативы и причины отказа

Всё включить в 0.1 / строить свою альтернативу apt/dnf — отклонено.

## Последствия и ограничения

Решение обязательно для проектирования API, состояния и тестов. Если конкретная версия ОС не обеспечивает указанное поведение, нельзя объявлять поддержку этой комбинации без ограничения функциональности. Любое изменение решения требует новой superseding ADR и подтверждения владельца проекта.

## Подтверждение

Критерии в `docs/ru/testing/release-gate.md` и границы в `docs/ru/product/scope-0.1.md`.
