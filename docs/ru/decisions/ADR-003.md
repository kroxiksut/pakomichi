# ADR-003 — Не поставлять системные зависимости из стороннего Git

[English](../../en/decisions/ADR-003.md) · **Русский**

**Статус:** принято как проектное решение (концепция); эксплуатационные свойства проверяются исследованиями.
**Дата:** 2026-10-18.

## Контекст

Запрещаем частичную миграцию дистрибутива и не становимся системным solver. Полная безопасность будущих транзакций не гарантируется без контроля чужих репозиториев.

## Решение

Pakomichi предоставляет только разрешённые прикладные пакеты/компоненты. Зависимости разрешает штатный менеджер из уже настроенных источников; явно несовместимые сборки не публикуем. Не делать глобальных хуков APT/DNF.

## Альтернативы и причины отказа

Автоматический Git dependency discovery / замена glibc из следующего дистрибутива / глобальный apt hook — отклонены.

## Последствия и ограничения

Решение обязательно для проектирования API, состояния и тестов. Если конкретная версия ОС не обеспечивает указанное поведение, нельзя объявлять поддержку этой комбинации без ограничения функциональности. Любое изменение решения требует новой superseding ADR и подтверждения владельца проекта.

## Подтверждение

R-001 проверяет реальные транзакции, в т.ч. dependencies и downgrade scenarios.
