# ADR-008 — Атомарные поколения репозиторных снимков

[English](../../en/decisions/ADR-008.md) · **Русский**

**Статус:** принято как проектное решение (концепция); эксплуатационные свойства проверяются исследованиями.
**Дата:** 2026-10-18.

## Контекст

APT/DNF могут получать метаданные параллельно. Атомарность одной записи `current` без immutable индексов недостаточна.

## Решение

Immutable generations. APT `Acquire-By-Hash`, content-addressed package paths, проверка подписей и ссылок до публикации. RPM repomd плюс индексы согласованы. Старые поколения удерживаются по ссылкам.

## Альтернативы и причины отказа

Перезаписывать Packages/RPM metadata на месте / удалять файлы активных поколений по таймеру — отклонено.

## Последствия и ограничения

Решение обязательно для проектирования API, состояния и тестов. Если конкретная версия ОС не обеспечивает указанное поведение, нельзя объявлять поддержку этой комбинации без ограничения функциональности. Любое изменение решения требует новой superseding ADR и подтверждения владельца проекта.

## Подтверждение

R-004, особенно при параллельном apt update/upgrade и прерванной публикации.
