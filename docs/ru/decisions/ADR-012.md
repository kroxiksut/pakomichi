# ADR-012 — Нативные версии и явная миграция поставщика

[English](../../en/decisions/ADR-012.md) · **Русский**

**Статус:** принято как проектное решение (концепция); эксплуатационные свойства проверяются исследованиями.
**Дата:** 2026-10-18.

## Контекст

NetWatch показал два RPM с одним именем, но разной динамикой libpcap и разным происхождением.

## Решение

Tag GitHub и native DEB/RPM version храним отдельно. Никогда не переписывать NEVRA/version. Migration между COPR/официальным repo/GitHub или вариантами сборки — явная операция с проверкой плана.

## Альтернативы и причины отказа

Считать любой greater Git version допустимой заменой / изменять epoch/release / скрытый fallback на fork — отклонено.

## Последствия и ограничения

Решение обязательно для проектирования API, состояния и тестов. Если конкретная версия ОС не обеспечивает указанное поведение, нельзя объявлять поддержку этой комбинации без ограничения функциональности. Любое изменение решения требует новой superseding ADR и подтверждения владельца проекта.

## Подтверждение

R-001 и E2E NetWatch (без изменения реальной пользовательской системы).
