# ADR — реестр принятых решений

[English](../../en/decisions/INDEX.md) · **Русский**

Каждый ADR содержит мотивировку, альтернативы, последствия и ссылку на подтверждение. Статус «принято» **не означает**, что проведены технические испытания. Для пересмотра создавать новый документ с указанием `supersedes`; исходный сохранять.
