# ADR-004 — Источник и одинаковые версии: отказ от неоднозначной автоматики

[English](../../en/decisions/ADR-004.md) · **Русский**

**Статус:** принято как проектное решение (концепция); эксплуатационные свойства проверяются исследованиями.
**Дата:** 2026-10-18.

## Контекст

APT pin выбирает версию, не гарантирует конкретный экземпляр равной версии; нельзя обещать больше, чем способен пакетный менеджер.

## Решение

Каждый Git-источник — отдельный логический repo; APT `Origin/Label/Suite` и адресный pin, DNF repo ID/priority/includepkgs. Если одинаковая нативная версия из разных источников имеет разные байты и выбор нельзя доказать, конфликтующий пакет только observing/held.

## Альтернативы и причины отказа

Менять native version суффиксом / тихо править чужие источники / полагаться на статус нашей БД — отклонено.

## Последствия и ограничения

Решение обязательно для проектирования API, состояния и тестов. Если конкретная версия ОС не обеспечивает указанное поведение, нельзя объявлять поддержку этой комбинации без ограничения функциональности. Любое изменение решения требует новой superseding ADR и подтверждения владельца проекта.

## Подтверждение

R-001. Обязательный отрицательный тест с двумя одинаковыми версиями и разными sha.
