# Сценарии использования и ожидаемое поведение

[English](../../en/product/scenarios.md) · **Русский**

**UC-01, первый пакет:** пользователь указывает конкретный Git URL; Pakomichi закрепляет ID, проверяет выпуск/пакет и конфликт имён, затем предлагает активировать разрешённый пакет. После активации — обычное `apt install` или `dnf install`.

**UC-02, несколько пакетов из одного CI:** один Git-репозиторий публикует приложение, CLI, службу, общие компоненты; все могут составлять разрешённое семейство. Нативные зависимости между ними разрешаются без подключения новых Git-проектов.

**UC-03, пакет уже есть в ОС:** первоначально предпочтителен штатный источник; пользователь явно выбирает Git при необходимости. Никакого автоматического переключения от одного поставщика к другому.

**UC-04, Git и системный репозиторий дают одну версию, разные файлы:** нельзя достоверно выбрать нужные байты только pinning APT; Pakomichi не активирует конфликтующее автоматическое обновление без доказанного безопасного способа.

**UC-05, требуются несовместимые системные библиотеки:** не искать библиотеки в другом Git-проекте; отклонить неподходящую версию. Системное обновление ОС управляется системным пакетным менеджером.

**UC-06, перенос репозитория:** ID прежний, владелец сменился — приостановить обновления до явного подтверждения переноса. Новый Git-проект со старым именем не наследует доверие.

**UC-07, GitHub недоступен:** прежний проверенный снимок доступен лишь в пределах установленного срока актуальности; пакет без локальных байтов невозможно установить офлайн; чужие системные источники не изменяются.

**UC-08, отключение/удаление:** удалить только запись об источнике/наши правила, не удалять установленные программы и не переписывать чужие файлы.

**UC-09, стороннее изменение состояния:** если администратор выполнил `dpkg -i`, отключил repo или настроил DNF, обнаружить расхождение и не выдавать внутреннюю базу за единственный источник истины.

**UC-10, форк/другой репозиторий автора:** даже версия `999.0` другого проекта никогда не принимается как обновление существующего источника.
