# Pakomichi visual assets

This directory contains the initial Pakomichi visual concept. It is suitable for repository documentation and design exploration, but it is not yet a final production logo system.

## Layout

```text
assets/
├── brand/
│   ├── pakomichi-brandboard.svg
│   ├── pakomichi-brandboard.png
│   ├── pakomichi-icon.svg
│   ├── pakomichi-icon.png
│   ├── pakomichi-mascot.svg
│   └── pakomichi-mascot.png
└── readme/
    ├── pakomichi-header-en.svg
    └── pakomichi-header-ru.svg
```

- `brand/` contains the full concept board, the square icon prototype, and the Pako mascot. SVG is the editable source; PNG is a preview and raster fallback.
- `readme/` contains localized, accessible SVG headers used by `README.md` and `README.ru.md`.

## Visual direction

- Forest: `#315A4E`
- Sage: `#789A78`
- Paper: `#F7F0DF`
- Parcel: `#E4AD71`
- Scarf: `#DE805F`
- Primary tagline: **Every package finds its way.**
- Primary command: **`pchi`**; full alias: **`pakomichi`**.

Pako is an original small forest guide carrying software packages from GitHub Releases to native operating-system repositories. The character must not imitate recognizable characters owned by animation studios or other projects.

Before production use, simplify and test the icon at small sizes, on dark backgrounds, and in monochrome. See [`LICENSING.md`](../LICENSING.md) for the distinction between documentation artwork, source material, and Pakomichi branding rights.
